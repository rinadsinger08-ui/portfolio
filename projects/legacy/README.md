# Original project source

These directories contain **readable source recovered from seven public Code.org projects** plus the served HTML/CSS for two Web Lab websites.

- Each Code.org `main.js` is the project JavaScript extracted from the public source export.
- App Lab/Game Lab runtime APIs, design metadata, media, sounds, and hosted AI models remain platform-dependent; use the linked original demos to run those projects.
- The Web Lab folders preserve the HTML/CSS source. Their media remains available through the original hosted websites.

These snapshots make the original implementation reviewable directly on GitHub. Importing them does not fix bugs in the original projects. Runnable standalone code and tested edge-case handling live in [the new Pet Decider](../pet-decider/).
