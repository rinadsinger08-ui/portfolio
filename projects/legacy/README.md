# Original project source

These directories contain **unmodified exports of seven public Code.org projects** and the served source of two Web Lab websites, fetched on 2026-10-04 (UTC).

Each `main.js` is extracted directly from the corresponding `main.json` source field. App Lab projects also include exported `design.html`. Game Lab exports include animation metadata in `main.json`; images, sounds, AI models, and Code.org runtime libraries remain hosted on the platform.

The two website directories contain the HTML and CSS as served plus project-local media. HTML preserves the injected Code.org footer. See their READMEs for provenance and any unavailable files.

These snapshots make the original implementation reviewable. Importing them does not fix bugs in the original projects. Runnable standalone code and tested edge-case handling live in [the new Pet Decider](../pet-decider/).
